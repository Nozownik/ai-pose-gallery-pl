# Custom outfits (CUST-001…CUST-050)

`custom.json` (names, PL/EN keywords, generation prompts) is public.
The 50 images (`img/*.webp` 768×1152) and thumbnails (`thumbs/*.webp` 300×450) are **not published** in this repo;
they are kept locally and bundled only into APK builds (`app/src/main/assets/custom/` in the build project).
To rebuild without them, regenerate from the prompts in `custom.json`.
