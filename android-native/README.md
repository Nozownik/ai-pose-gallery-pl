# Galeria poz AI — natywne Android (Jetpack Compose)

Pakiet: `pl.nozownik.posegallery`  
Bez WebView. Dane: `assets/data/pose-en.json` (w APK). Obrazki: CDN `https://ai-pose-gallery.pages.dev/`.

Pełny projekt Gradle: osobny katalog buildowy `ai-pose-gallery-pl-app` / release APK na GitHub Releases.

Funkcje: siatka 2 kolumny, filtry (system/kategoria/kąt), szukaj, ulubione, szczegół + **Kopiuj tagi EN**.
