# Native Android app (Jetpack Compose) — Galeria poz AI

Package: `pl.nozownik.posegallery`  
Buildable project lives in sibling checkout `ai-pose-gallery-pl-app` (or copy these sources into an Android Studio module).

## v2.1.0 features
1. Single **Kopiuj / Copy** (EN tags) → clipboard; long-press hint copies ID
2. **Zapisz obraz** → MediaStore `Pictures/GaleriaPozAI`
3. **Ustawienia**: język PL/EN, motywy Dark / AMOLED / Light / Purple / Cyan
4. Category/filter chip tap scrolls grid to top
5. **Dodaj własną** pozę (image + schema fields), badge, delete
6. Style prompts: Nano Banana, ChatGPT, Grok Imagine (one-tap copy)
7. Per-pose **adnotacje** (local notes)
8. Settings → **Linki (free)** pose-reference sites

Version: 2.1.0 (versionCode 3)
